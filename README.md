PyBot — Console Chatbot with Quiz

 A fun and interactive rule-based Python chatbot that can chat, tell jokes, share facts, solve basic math, reverse text, check palindromes, and host a multi-category quiz — all in your console.

✨ Features

    Friendly chat: hello, how are you, bye

    Utilities: reverse, upper, lower, count, pal

    Math: add, sub, mul, div

    Fun: compliment, joke, fact, riddle

Quiz categories: general, science, tech, geo with hints & lifelines

Shows and resets your score

🧠 Concepts Used

    Functions • Loops • if/elif • Input/Output • Strings
